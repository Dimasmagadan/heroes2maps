# Fixtures

Test maps bundled for byte-exact codec round-trips (`test/roundtrip.test.ts`
re-encodes every map byte-for-byte) and for calibrating the generator.
They are community maps made for [fheroes2](https://github.com/ihhub/fheroes2),
not original game assets. The authors below are credited in each map's own
embedded metadata.

| Map | Author (from the map's metadata) |
|---|---|
| 7_deserts.fh2m | WinnymaruBaba (2026), Russian translation by Makso, edited by Ihhub |
| Apocalypse.fh2m | BorasDK (v3.7) |
| Eruption.fh2m | Moucheron Quipet (2025, updated 2026, v3.2) |
| Final_Invasion.fh2m | BorasDK (v7.9) |
| Good_Titans,_Bad_Titans.fh2m | YhyJasne (v1.1.1) |
| Lost_Temple.fh2m | a classic map reimagined for fHeroes2 (v1.1.17, homm2.com) |
| Ravenhold.fh2m | BorasDK (v1.9) |
| Tetra_conflict.fh2m | Tobal (The Ever Padawan Archives) |
| Utopeia.fh2m | YhyJasne (v1.5.4) |

The maps are redistributed here under the same GPL-2.0-or-later terms as the
rest of this project. If you made one of these maps and would rather it not be
bundled here, please open an issue and it will be removed.
